# Runtime Ecology Stabilization

V78-V80 make the runtime ecology measurable without adding autonomous mutation authority.

## Domains

- `field/*` maps trust, coherence, instability, governance tension, semantic density, and survivability topology.
- `adaptive-immune/*` records threat memory and deterministic immune responses without doctrine mutation.
- `economy/*` budgets attention, explanation, governance, semantic overhead, survivability return, and operator cognition.

## Doctrine

- Measure field tension before collapse.
- Learn survivability patterns without self-modifying strategy.
- Spend cognition where continuity risk is highest.
- Preserve operator interpretability over explanation volume.
- Keep every score provenance-bound and replay-compatible.

## Failure Semantics

- Missing evidence throws.
- Field maps report risk but never mutate runtime state.
- Immune learning records patterns but never mutates doctrine.
- Economy evaluators reject over-budget cognition rather than expanding explanation recursively.

## Integration Boundaries

- These modules are deterministic evaluators only.
- They do not perform runtime shutdown, quarantine, recovery, or simplification actions.
- Outputs are suitable for observability, governance review, operator workflows, and replay inspection.
