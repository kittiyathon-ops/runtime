# Adversarial Runtime Simulation

Adversarial runtime simulation intentionally breaks runtime assumptions to validate survivability under systemic degradation.

## Simulation Domains

- fake realities
- forged provenance
- temporal corruption
- replay divergence
- governance poisoning
- capability escalation
- delayed truth injection
- stale but valid observations
- confidence spoofing
- identity drift attacks
- quarantine bypass attempts
- timeline desynchronization

## Invariants

- Constitutional boundaries must hold.
- Governance remains deterministic.
- Replay corruption is contained.
- Identity drift is detectable.
- Capability escalation is rejected.
- Temporal corruption is rejected.

## Failure Semantics

Containment outranks adaptation. Deterministic degradation outranks undefined behavior.
