# V4.5.1 Deterministic Survivability Upgrade

## Migration Notes

V4.5.1 introduces three deterministic control layers:

- `src/infrastructure/PrecisionMath.ts`
- `src/core/SurvivabilityProvider.ts`
- `src/bridge/RequestGovernor.ts`
- `src/core/StartupTruthReconciler.ts`
- `src/bridge/RestApiGovernor.ts`
- `src/bridge/WebSocketSequenceIntegrity.ts`
- `src/bridge/ExchangePayloadGuard.ts`
- `src/infra/RuntimeSessionLock.ts`
- `src/core/StateManager.ts`

Financial comparisons must use `PrecisionMath` or integer-scaled values. Do not introduce `number` arithmetic for order quantity, price, notional, PnL, fees, funding, margin, or exposure.

Runtime integrity failures now use `GOVERNANCE_HALT` before terminal shutdown. `GOVERNANCE_HALT` blocks ingestion and order submission, preserves evidence, and requires operator/governance review before any restart path.

`HIBERNATION_MODE` suspends new execution after repeated REST instability while allowing bounded health monitoring and non-execution runtime observation. It is a degradation state, not an automatic recovery bypass.

The request governor does not retry requests. It returns explicit decisions: `ALLOW`, `QUEUE`, or `REJECT`. Queued work is released only by explicit `drain(nowMs)` calls, making rate-limit behavior replay-safe and auditable.

## Failure Modes

| Failure | Detection | Runtime Action |
| --- | --- | --- |
| Exchange/local divergence | `SurvivabilityProvider` exchange confidence | `GOVERNANCE_HALT` |
| Ghost order | Governance trigger | `GOVERNANCE_HALT` |
| Orphan fill | Governance trigger / runtime orphan-fill check | `GOVERNANCE_HALT` or existing safe-mode path |
| Mutable replay history | Replay integrity input | `GOVERNANCE_HALT` |
| Missing / duplicate / out-of-order sequence | Replay integrity input | `GOVERNANCE_HALT` |
| Exposure cap breach including partial fills | Decimal-safe exposure projection | `GOVERNANCE_HALT` |
| Binance 429 risk | `RequestGovernor` token/queue state | `QUEUE` or `REJECT` |
| Observed Binance rate limit | `observeRateLimit` | `REJECT` with `retryAfterMs` evidence |
| Startup truth divergence | `StartupTruthReconciler` comparing replay, balances, positions, open orders | `GOVERNANCE_HALT` |
| Duplicate runtime instance | `RuntimeSessionLock` PID/session lock | Startup rejected |
| WebSocket sequence gap | `WebSocketSequenceIntegrity` update ID continuity | Bounded resync then quarantine |
| Compound stale feed risk | stale duration + WS health + ack drift + sequence + reconciliation confidence | `DEGRADE`, `SAFE_MODE`, or `HIBERNATION_MODE` |
| REST instability | `RestApiGovernor` bounded retry/circuit state | explicit retry, reject, or `HIBERNATION_MODE` |
| Fatal auth state | HTTP 401/403 or invalid API key code | fatal shutdown lifecycle and `GOVERNANCE_HALT` |
| Poison payload | `ExchangePayloadGuard` size and JSON object validation | reject packet / partition evidence |
| Expected funding drift | startup ledger delta category `funding_fee` | accepted if the expected delta reconciles |
| SQLite flush instability | bounded event-store flush | audit `event_store_flush_failed`, halt risk, enter safe mode where possible |

## Operational Rules

1. Survivability outranks profitability.
2. `GOVERNANCE_HALT` is not automatically recoverable.
3. Request retries must be explicit, bounded, observable, and audited.
4. Hot execution paths must not perform blocking external IO.
5. Snapshot refresh, reconciliation, notification, and persistence orchestration must remain outside order submission.
6. Replay history remains append-only; never rewrite historical event records to repair state.
7. Startup reconciliation must fetch exchange truth before live activation and compare it with replayed local truth.
8. Funding fees are explicit expected ledger deltas, not corruption, when evidence-bound.
9. Fatal auth errors are not retryable and must not enter hibernation; they halt governance authority immediately.
10. SQLite persistence is append-buffered and flushed by explicit non-hot-path control points.
11. Notification delivery remains asynchronous and must not block execution.

## Implementation Notes

`SurvivabilityProvider` is pure decision logic except for `EmergencyStop` record creation when it returns `GOVERNANCE_HALT`. It consumes evidence-bearing inputs and emits explainable reasons and score.

`RequestGovernor` is deterministic because token refill depends only on caller-supplied `nowMs`. It uses a bounded in-memory queue and exposes queue depth and retry timing as evidence.

`PrecisionMath` uses decimal strings and `bigint` scaling. It rejects invalid decimals, undefined values, `NaN`, and values that exceed the requested scale.

`PrecisionMath` exposes exchange-facing helpers: `applyTickSize`, `applyStepSize`, `safeCompare`, `normalizeQuantity`, and `normalizePrice`. Division and multiplication are integer-scaled and reject invalid inputs.

`StartupTruthReconciler` is pure reconciliation logic. The bootstrap layer records `startup_truth_reconciliation_failed`, enters `GOVERNANCE_HALT`, and stops activation when reconciliation fails. It does not cancel orders or mutate exchange state.

`RestApiGovernor` wraps `RetryPolicy` decisions into operational actions. It does not sleep or execute retries itself; callers must persist/audit decisions and schedule retries outside the hot path.

`ExchangePayloadGuard` bounds websocket and REST payload parsing. User stream payloads must parse as JSON objects before execution report normalization.

`SqliteEventStore` uses a bounded in-memory append buffer and explicit transaction flushes. Runtime event acceptance appends to the buffer without waiting on SQLite disk flush timing. Flushes occur during health reporting, replay reads, and shutdown. If the buffer is full or flush fails, the runtime records evidence and fails closed.

`StateManager` adds alpha measurement without strategy logic. It tracks MAE, MFE, fill drift, temporal latency, acknowledgement delay, and realized-vs-expected execution quality from replayed runtime events. MAE/MFE use mark-price or execution-aware observations and do not infer excursions from candle extremes.
