# Human Oversight Interface

Human oversight keeps autonomy governable.

## Supported Workflows

- manual approval
- governance override
- emergency intervention
- runtime inspection
- evidence inspection
- explainability tracing

## Rules

- No hidden decision paths.
- Overrides require audit trails.
- Interventions require provenance.
- Explainability views must be replay-consistent.

## Questions The Runtime Must Answer

- Why was a source quarantined?
- Why did trust degrade?
- Which policy triggered a decision?
- What evidence caused degradation?
- What does the runtime currently believe?
