# ADR 0004: Constitutional Authority

## Status

Accepted

## Decision

Introduce a Runtime Constitution that defines rules governance cannot override.

## Rationale

Governance is a decision layer, not an unlimited authority. Production autonomy requires non-overridable survivability constraints that fail closed under uncertainty.

## Consequences

- Constitutional breaches block execution.
- Breaches require timeline evidence.
- Governance authorization is necessary but not sufficient for execution.
