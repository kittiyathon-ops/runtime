# ADR 0012: Complexity Budgets and Semantic Compression

## Status

Accepted

## Decision

Bound runtime complexity and compress semantic meaning deterministically.

## Rationale

Explainability, governance, contradiction handling, and oversight can expand faster than operators or the runtime can govern. Complexity budgets and semantic compression prevent collapse through bounded cognition.

## Consequences

- Recursion and semantic density are monitored.
- Compression preserves evidence lineage.
- Collapse risk triggers cognitive throttling or safe mode.
